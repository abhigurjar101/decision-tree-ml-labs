# Decision-tree machine-learning labs

Two reproducible scikit-learn exercises by **Abhi Kumar Gurjar**: binary classification on synthetic loan records and regression on synthetic house-price records. They demonstrate interpretable trees, held-out metrics, training-set cross-validation, hyperparameter search and pruning.

![Tests](https://github.com/abhigurjar101/decision-tree-ml-labs/actions/workflows/tests.yml/badge.svg)

## Run

```bash
git clone https://github.com/abhigurjar101/decision-tree-ml-labs.git
cd decision-tree-ml-labs
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m unittest discover -s tests -v
python decision_tree_classification.py
python decision_tree_regression.py
```

The full scripts include grid searches and take longer than the small test suite. Input paths resolve relative to the source files, so the scripts also work from another working directory. Optional figure regeneration: `MPLBACKEND=Agg python generate_assets.py`. This overwrites the bundled synthetic CSV fixtures and creates local plots in `assets/`.

## Data provenance

Both CSVs were generated by the supplied `generate_assets.py` using fixed random seeds. They do not represent real borrowers, lending outcomes, properties or market prices. The generator embeds relationships into labels and targets; strong scores on these fixtures are not evidence of real-world predictive accuracy.

| Dataset | Features | Target |
|---|---|---|
| `data/bank_loan_data.csv` | Synthetic income, credit score, existing debt and loan amount | `Approved` (0/1) |
| `data/house_prices_data.csv` | Area, bedrooms, distance and property age | `Price_k$` |

## Method

Both exercises reserve 25% of the data for a seeded test split. Classification stratifies by label and reports accuracy, precision, recall, F1, confusion matrix and ROC-AUC. Regression reports MAE, MSE, RMSE and R². Cross-validation and grid search use only the training partition; the held-out partition is not used to choose grid-search parameters. The scripts show baseline and tuned results, so a future experiment should use an additional validation/final-test protocol if repeatedly choosing between approaches.

The classification lab also prints cost-complexity pruning candidates. The regression lab explains why depth-limited trees produce piecewise-constant predictions. No business uplift or production-readiness claim is made.

## Verification

Two tests fit actual models on fixed train/test splits, check fixture integrity and model-depth behavior, and compare against simple dummy baselines. These are regression checks on synthetic examples, not a published benchmark. CI runs the same tests.

## Structure

- `decision_tree_classification.py`: classification, tuning and pruning exploration
- `decision_tree_regression.py`: regression and tuning
- `generate_assets.py`: seeded synthetic data and explanatory plot generation
- `data/`: synthetic fixtures
- `tests/`: model and fixture checks

This educational loan example must not be used to make real lending decisions. External validation, fairness evaluation, calibrated uncertainty and domain review are outside its scope.
